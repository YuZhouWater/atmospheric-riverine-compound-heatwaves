# Data description

This directory contains the datasets used for event detection, model training and evaluation, sensitivity analyses, and future projections.

| File | Description |
|---|---|
| `ARCH_frequency_by_time_gap.csv` | Data used for sensitivity analyses under different compound-event time windows. |
| `Future_heatwave_duration.csv` | Data used for future projections of heatwave duration and compound-event proportions. |
| `AHW_RHW_metric.csv` | Metrics characterizing atmospheric heatwaves (AHWs) and riverine heatwaves (RHWs). |
| `Example_40_rivers_Tmax.csv` | Example daily maximum air temperature data for detecting AHWs and atmospheric–riverine compound heatwaves (ARCHs). |
| `Example_40_rivers_WT.csv` | Example water temperature data for detecting RHWs and ARCHs. |
| `Example_40_rivers_DO.csv` | Example dissolved oxygen data for the selected rivers. |
| `Attribute_data.csv` | Static basin attributes used as input variables for the long short-term memory model. |
| `Observed_DO_796_rivers.csv` | Observed dissolved oxygen data used for model training and evaluation. |
| `Observed_WT_796_rivers.csv` | Observed water temperature data used for model training and evaluation. |
